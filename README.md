# 🌌 AI Studio

**AI Studio** is a premium, local-first, agentic IDE designed for high-performance development. It combines the power of local Large Language Models (via Ollama) with a sophisticated multi-pane management system and autonomous agent capabilities.

![AI Studio Screenshot](https://via.placeholder.com/1200x600/0f0f12/5865f2?text=AI+Studio+Premium+Interface) *(Add real screenshot here)*

## ✨ Key Features

- **🛡️ Local-First & Private**: Everything runs on your machine. No cloud dependencies, no API keys, total privacy.
- **🤖 Autonomous Agents**: Built-in agents can read your code, write files, and execute terminal commands to solve complex tasks.
- **🔲 Multi-Pane Architecture**: Powered by FlexLayout. Run multiple models or roles (Architect, QA, Developer) simultaneously in a fully customizable workspace.
- **🛠️ System Integration**: Deep integration with your filesystem and terminal, protected by a **Human-In-The-Loop (HITL)** approval system.
- **📊 Real-time Stats**: Monitor your Hardware (RAM, VRAM, CPU) usage directly within the IDE.
- **🎨 Premium Aesthetics**: A state-of-the-art glassmorphic UI designed for developers who appreciate beauty and function.

## 🚀 Getting Started

### Prerequisites
- [Ollama](https://ollama.com/) installed and running.
- [Node.js](https://nodejs.org/) (v18 or higher).

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/username/ai-studio.git
   cd ai-studio
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run in development mode:
   ```bash
   npm run dev
   ```
